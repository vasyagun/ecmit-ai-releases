## Основные изменения

- надёжное восстановление локальной истории при сетевой ошибке;
- идемпотентная синхронизация хода до и во время длительной задачи;
- дисковая очередь повторной синхронизации Windows-клиента;
- прикрепление XLSX кнопкой без ручного ввода пути;
- запрет перехода к PowerShell и Excel COM после ошибки серверной файловой операции.
