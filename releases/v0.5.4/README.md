# ECMIT AI 0.5.4

Выпуск Windows-приложения и подписанного APK для RuStore.

## Файлы

- `ECMIT-AI-Setup-0.5.4.exe` — установщик Windows.
- `ECMIT-AI-0.5.4-android-rustore.apk` — APK для RuStore.

## Android

- package name: `su.ecmit.ai`
- version code: `5040`
- version name: `0.5.4`
- target Android API: `36`
- подпись: APK Signature Scheme v1 и v2

## Основное изменение

Потоковый ответ следует за нижним краем чата, но перестаёт автоматически прокручивать страницу, если пользователь поднялся выше и читает предыдущий текст.

В выпуск также входят надёжная синхронизация истории и прикрепление XLSX из версии 0.5.3.
