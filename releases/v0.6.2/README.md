# ECMIT AI 0.6.2

Релиз для Windows.

## Основные изменения

- Исправлен резервный вход сотрудников: используются email и одноразовый код, вручную созданный в личном кабинете `ecmit.su`.
- Удалено ошибочное предложение отправить код на электронную почту.
- Сохранён отдельный вход модератора RuStore по email и паролю без доступа к внутренним данным ECMIT и RAG.
- Основной вход сотрудников через Yandex ID продолжает работать через системный браузер.
