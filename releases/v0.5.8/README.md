# ECMIT AI 0.5.8

Выпуск Windows, macOS и подписанного APK для RuStore.

Ошибка отдельной локальной PowerShell- или zsh-команды больше не завершает всю задачу. Агент получает диагностический результат и может исправить команду либо выбрать другой способ.
