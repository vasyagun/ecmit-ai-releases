Первая подписанная Android-сборка для закрытого тестирования через RuStore.

## Файл

`ECMIT-AI-0.5.0-beta.3-android-rustore.apk`

- package name: `su.ecmit.ai`
- version code: `5003`
- minimum Android API: `23` (Android 6.0)
- target Android API: `36`
- подпись: APK Signature Scheme v1 и v2
- SHA-256: `6CDE510A41E8EAB863FC4C61BB27755674C1EB60991E74EE6AE7DABF5B3847D5`

## Что нового

- отдельный RuStore-канал без установки обновлений с GitHub;
- обновление Android API до 36;
- новая постоянная подпись для этой и всех последующих Android-версий.

Предыдущая beta-сборка была подписана другим ключом. Перед установкой этой версии её нужно удалить. Все следующие версии с текущей подписью будут обновляться без удаления приложения.
