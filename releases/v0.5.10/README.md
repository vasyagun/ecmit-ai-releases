# ECMIT AI 0.5.10

Релиз для Windows, Ubuntu и Android (RuStore).

## Основные изменения

- Окно «Что нового» корректно отображает безопасную HTML-разметку вместо исходных тегов.
- В desktop-интерфейсе появился индикатор заполнения контекста модели с точными или оценочными значениями по наведению.
- При приближении к лимиту приложение автоматически создаёт краткое резюме ранней части беседы и продолжает задачу без очистки видимой истории чата.
- Данные об использовании токенов сохраняются вместе с локальной историей разговора.
