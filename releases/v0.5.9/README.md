# ECMIT AI 0.5.9

Выпуск Windows, полноценной Ubuntu AppImage и подписанного APK для RuStore.

## Основное изменение

Ubuntu стала официальной desktop-платформой: доступны чат и история ECMIT, локальный агент, вложения, рабочие папки, обработка документов и автообновление. Локальный агент умеет выполнять подтверждённые Bash-команды, находить приложения, проверять CUPS-принтеры и читать сведения о системе.
